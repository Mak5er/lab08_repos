## Опис завдань (Варіант 23)

### Завдання № 8.1: Пошук та заміна символів у літерному рядку
Дано літерний рядок, який містить послідовність символів $s_0, \dots, s_n, \dots$. Відомо, що серед цих символів є по крайній мірі три коми.
1. Знайти число $i$ таке, що $s_i$ — третя за порядком кома.
2. Замінити кожну кому парою зірочок `**`.

Реалізовано 4 способами відповідно до інструкцій кафедри:
- **Ітераційний спосіб (`char[]`)** — ручне посимвольне сканування масиву символів.
- **Рекурсивний спосіб (`char[]`)** — рекурсивний спуск та заміна без використання ітераційних циклів.
- **Стандартні функції мови C (`char[]`)** — використання функцій бібліотеки `<cstring>` (`strchr`, `strncat`, `strcat`, `strcpy`).
- **Стандартні функції мови C++ (`string`)** — використання класу `std::string` та його методів `find` і `replace`.

### Завдання № 8.2: Опрацювання літерних рядків
Дано літерний рядок, який містить послідовність символів $s_0, \dots, s_n, \dots$. Підрахувати довжину найдовшого слова в цій послідовності (*слово* — це група символів, які розташовані поспіль і відмінні від пробілів та знаків пунктуації).
